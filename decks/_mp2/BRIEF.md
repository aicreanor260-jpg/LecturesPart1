# Дека MPLS 2.9 — переделка в подаче v2

Автор забраковал прежнюю подачу: (1) инфографика была «картинкой в картинке» — отдельная подложка поверх фона слайда;
(2) текст pptx вывален простынёй в карточку, а рядом слайд-дубль «инфографика» — логики нет.

**Новая подача (эталон — `_mp2_s1.py`, pptx 3–5; посмотри `_mp2/shots/_mp2_s1/sheet.png` и все `NNN.png`):**
- Фон слайда = чистый фон комплекта (`bgk_NN`, список с персонажами — `_mp_rep/BGLIST.md`, картинки — `_mp_src/bgk_NN.png`).
  Бери тот фон, что стоит у вёрстки этой инфографики (`grep bg\( _mp_rep/iNNa.py`), если персонажи не мешают раскладке.
- Один слайд pptx = одна композиция. Слайдов-дублей «инфографика» НЕТ. Если не влезает — разбей на 2–3 слайда
  по смыслу (одинаковый заголовок pptx, разные label: «pptx N · Подтема»), порядок как в pptx.
- Текст слайда pptx — ДОСЛОВНО и ВЕСЬ (он уже набран в старых модулях `_mp_s1.py`/`_mp_s2.py`/`_mp_s3.py` — бери оттуда:
  там же исправлены явные опечатки), но разнесён по смысловым блокам: панели с заголовками блоков. Заголовки блоков,
  пилюли, короткие выводы, подписи схем — бери из инфографики автора (`_mp_src/iNNa.png`, смотри Read; её вёрстка с текстами —
  `_mp_rep/iNNa.py`). От себя ничего не придумывать.
- Схема/картинка инфографики — живой вёрсткой в панели (цепочки узлов, пакеты с метками, таблицы), раскрытие по шагам (`step`)
  вместе с соответствующим текстом. Готовые SVG-сцены с кнопками «Назад/Вперёд» из старых модулей можно и нужно переиспользовать:
  `from _mp_s1 import two_domains, mpls_hdr, arch, stack_ops, two_paths`, `from _mp_s2 import ldp_scene, rsvp_scene, te_net, seq`,
  `from _mp_s3 import ping_scene, te_tunnels, prot_all, frr_scene, sr_scene, sr_net, svc_paths, te_example, te_net60, frac`
  и `from _mp_fig import sc, svg` (сцена: `sc(body, подписи, viewBox)`; статичная: `'<div class="figwrap mppanel">'+svg(...)+'</div>'`).
  Рисунки pptx (`scratchpad media`) уже перерисованы в этих функциях — значения меток/узлов/адресов не менять.
- Иконки/маршрутизаторы/здания — вырезки `_mp_rep/crops/*.png` через `ico("файл.png", высота)`; новые вырезки:
  `python -X utf8 _mp_rep/_crop.py iNNa x0 y0 x1 y1 iNNa_что.png key`.
- Блоки кита (`_mp2_kit.py`, читай целиком): `slide(label, bg, title, body, safe="sr")`, `panel(head, html, "or|gr|rd|tint", num)`,
  `row(...)`, `step(...)`, `pk([метки])`, `node(img, имя, подпись)`, `arrow()`, классы `m2big`, `m2note`, `m2pill bl|or|gr`,
  `m2zone` + `m2zl`, `m2tbl`, `m2cap`, `m2flt`. Свой CSS — только в своём модуле: константа `CSS = "..."` (сборщик подхватит),
  классы с префиксом своего модуля.
- Текст крупный (проектор), без пустой нижней половины и без переполнения. Персонажи фона не закрываются заголовком
  (`safe="sr"` когда персонаж справа вверху; `"sl"` — слева).

## Как работать
1. Модуль `_mp2_sN.py` с функцией `build()` (импорты как в `_mp2_s1.py`), label каждого слайда начинается с `pptx N · `.
2. Проверка: `python -X utf8 _mp2/shot.py _mp2_sN` → `_mp2/shots/_mp2_sN/sheet.png` и `NNN.png`; смотри Read.
   Строки «ПЕРЕПОЛНЕНИЕ» должно не быть, «ошибки JS []». 2–3 итерации до хорошего вида.
3. Трогаешь только свой `_mp2_sN.py` и свои новые вырезки. Git не трогать, `mpls.html` не собирать.
4. Отчёт кратко по-русски: слайды (label), что непохоже/спорно.
