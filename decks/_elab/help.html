Сетевая лаборатория Eltex

Лёгкий эмулятор для лабораторных NTF2: коммутаторы MES (свой CLI MES24xx), маршрутизатор ESR (CLI ESR), компьютеры VPC и Debian. Работает в браузере, офлайн, на слабых ПК — без виртуальных машин. Это модель поведения по документации Eltex, а не прошивка устройства.

Как работать

  1. Добавьте устройства из палитры слева, перетащите на место.
  2. Кабель → щёлкните устройство → выберите порт → второе устройство → порт.
  3. Щёлкните устройство — справа откроется его консоль. Вкладки над консолью переключают устройства.
  4. ping в панели или из консоли — на схеме видно, как идут кадры: ARP-рассылка (жёлтый), ответ, IP-пакет (синий), теги VLAN на кабелях. Внизу — пошаговое объяснение: ◀ ▶ по шагам, ⏵ — заново.
  5. Лабораторные — готовые работы со случайным вариантом и проверкой после каждой команды. Задания — случайные задачи на один коммутатор.
  6. Сохранить / Открыть — схема со всеми настройками в файл .json.

В консоли: ? — что можно ввести дальше, Tab — дописать слово, ↑ ↓ — история. Сокращения работают: conf t, int gi1/0/1, sh vl.

switch>            enable

switch(config-if)# exit / end

Режимы ESR

vesr#                 configure
vesr(config)#         interface gigabitethernet 1/0/1  → (config-if-gi)#
vesr(config)#         interface gigabitethernet 1/0/1.10 → (config-if-sub)#
vesr(config)#         username master → (config-user)#
vesr(config)#         do commit   — применить
vesr(config)#         do confirm  — подтвердить

На ESR изменения не действуют до commit. Пакеты на интерфейс с включённым межсетевым экраном отбрасываются — нужна ip firewall disable.
