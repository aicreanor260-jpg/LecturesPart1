# Дека «Протокол OSPF» по pptx «OSPF 2 5» — общий бриф для агентов

Репозиторий лекционных HTML-дек. Собираем НОВУЮ деку `decks/ospf-2-5.html` строго по pptx (старую `ospf.html` и её модули `_ospf_*` НЕ трогать, только импортировать для чтения).
Материалы pptx: `decks/_o5_pptx/` — картинки по слайдам `sNN_imageK.png`, текст всех слайдов `decks/_o5_pptx/pptx.txt`.
Правила автора (обязательно прочитать): `.claude/skills/deck-builder/reference/pptx-rules.md`.

Главное:
- Ничего не выдумывать. Все тексты, адреса, порты, метрики, числа — ДОСЛОВНО как на картинке pptx. Нет подписей «Рисунок …».
- Опечатки/ошибки оригинала переносить как есть и перечислить в отчёте (например «UDR» вместо BDR).
- Стиль — кавайный пастельный, как инфографики автора (`decks/_o5_src/*.png`): белый/облачный фон, розовый #ff4f9a, голубой #2f8fe8, жёлтый, мятный, тёмный текст #1f1a33, сжатые жирные заголовки (Oswald 700), текст Golos Text, моноширинный JetBrains Mono. Скруглённые пастельные плашки r≈14–20.
- Текст крупный (проектор).
- Python запускать: `python -X utf8 ...` из папки `decks`. Git не трогать, деку не собирать, чужие файлы не править.
- Отчёт по-русски кратко: что сделано, что не вышло, найденные ошибки pptx.
