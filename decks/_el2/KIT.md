## Холст и вёрстка

- Холст ровно **1920×1080**, вёрстка **абсолютная**: `style="position:absolute;left:Xpx;top:Ypx;width:Wpx"`.
- Никакого flex-потока на уровне слайда — только внутри карточек.
- Поля: слева/справа 90–140px, заголовок обычно сверху по центру (`<h1 class="t ab ctr-x" style="top:40px;width:1500px">`).
- Размеры шрифтов как в референсе: заголовок слайда 56–68px, подзаголовки карточек 26–32px,
  основной текст 20–24px, мелкие подписи 18px.

## Готовые классы

| Класс | Что это |
|---|---|
| `card`, `card solid`, `card mint`, `card cream`, `card rose` | полупрозрачные карточки, как на референсах |
| `ch` | заголовок внутри карточки (синяя полоска слева), `ch sm`, `ch nb` (без полоски) |
| `b`, `b sm`, `b dim`, `lead` | абзацы текста |
| `t`, `big`, `kick`, `sub` | заголовки слайда |
| `chip`, `chip key` | светлая плашка / клавиша клавиатуры |
| `cmd` | тёмная плашка команды (моноширинный белый текст) |
| `badge`, `badge o` | синий квадратный номер шага / контурный |
| `num` | крупная бледная цифра 01/02 |
| `ico('имя')`, `ico('имя','sm')`, `ico('имя','hex')` | иконка в рамке; имена см. в `_el2_lib.py` (функция `icon`) |
| `tag`, `note`, `tbl` (`th.b2`, `th.b3`, `td.hl`) | тег, плашка-примечание, таблица |
| `mono` | моноширинный текст (все команды, адреса, числа) |

## Анимация

- `data-s="N"` на элементе — он появляется на шаге N (1, 2, 3 …). Элементы без `data-s` видны сразу.
- Стрелки: `arrow_svg(x1,y1,x2,y2,step)` внутри общего слоя
  `<svg class="ab" style="left:0;top:0;width:1920px;height:1080px;overflow:visible" viewBox="0 0 1920 1080">…</svg>`.
  Линия рисуется, наконечник появляется в конце.
- Задержка внутри шага: `style="--dl:120ms"`.
- 3–8 шагов на слайд. Заголовок слайда всегда виден сразу, без анимации.
- Логика шагов — смысловая: один шаг = один блок/пункт/стрелка.

## Фото

Что нельзя нарисовать (устройства, стойки, разъёмы, скриншоты web-интерфейса) — **вырезать из референса**:

```bash
python "C:/Users/anank/AppData/Local/Temp/claude/D--------------/scratch8/crop.py" p019 0.03 0.30 0.97 0.63 esr_front.jpg
# аргументы: референс, x0 y0 x1 y1 (доли), имя файла в _el2assets
```

В HTML: `<img class="cut ab" src="assets/esr_front.jpg" style="left:190px;top:330px;width:1540px">`
(`cut` — с тенью, без рамки; `ph` — со скруглением, для скриншотов).

Имена файлов — осмысленные и уникальные, с префиксом номера референса: `p019_esr200_front.jpg`.

## Правила текста

- Текст берём с референс-слайда дословно. Если на фото текст мелкий и нечитаемый — сверять с `pptx.txt`.
- Ничего не выдумывать: нет данных — не пишем.
- Никаких эмодзи. Никаких стрелок «→» в тексте (стрелки только графикой).
- Все команды, адреса, номера портов и моделей — моноширинным (`class="mono"`).

## Чего не делать

- Не менять `_el2_lib.py`, не добавлять внешние библиотеки и ссылки на CDN.
- Не вставлять фон в слайд: фон и морозные углы рисует движок.
- Не копировать референс целиком одной картинкой, если слайд можно собрать вёрсткой;
  фото — только для тех частей, что нарисовать нельзя.
