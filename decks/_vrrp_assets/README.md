# VRRP · 2.8

Самодостаточная HTML-лекция на движке проекта. Сборка из корня репозитория:

```powershell
python decks/_vrrp_build.py
```

Для сборки нужен Python с Pillow (общая зависимость существующих сборщиков). У готового `vrrp.html` нет внешних скриптов, шрифтов и ресурсов. Фоны встроены как WebP, схемы — inline SVG. Пометки и результаты тренажёров живут в памяти страницы.

`source-text.json` содержит текст исходных 29 слайдов. `_vrrp_tx.json` — расшифровка изображений с командами, таблицами и диагностическими выводами. `slide-map.json` связывает экраны лекции с номерами исходной PPTX (0 — практика и финал).

По пожеланию автора расхождения исходника сохранены и отмечены:

- Слайд 8: для 224.0.0.18 в тексте встречаются MAC `01:00:5E:00:00:12` и `01:00:5E:00:00:18`. Оба показаны; рядом приведено сопоставление из RFC 3768.
- Слайд 25: в колонке SW2 три приглашения написаны SW1. Команды перенесены дословно.
- Слайд 28: у приглашений `config-subif` отсутствует `#`. Сохранено дословно.
- Упрощённые формулировки про TTL и переход Backup → Master сохранены в полном тексте; технические уточнения вынесены в конец лекции.
- Один и тот же диагностический снимок на слайде 21 вставлен дважды. В лекции он транскрибирован один раз.

Справка для уточнений: https://www.rfc-editor.org/rfc/rfc3768.html . Лекция сохраняет терминологию Master/Backup и VRRPv2 исходной PPTX.

CLI — ограниченная учебная модель синтаксиса исходника. Она не подключается к оборудованию, не моделирует реальную передачу кадров и задержки выборов. Соседний маршрутизатор и коммутация в заданиях считаются заранее настроенными.

Параметр `?review=1` отключает визуальные переходы для проверки скриншотов. В обычном режиме анимация включена; учитывается системная настройка уменьшения движения.
