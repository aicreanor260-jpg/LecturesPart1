# Задача: инфографика 2.6 → живая вёрстка на чистом фоне

Дека `decks/ip-servisy-dhcp-nat-ntp.html` (DHCP/NAT/NTP, тёмно-синий неоновый стиль), сборка `python -X utf8 _i6_build.py` (из `decks/`).
Сейчас инфографики автора вставлены картинками. Для каждой своей инфографики сделай файл `decks/_dk_rep/<имя>.py` —
сборка покажет вёрстку вместо картинки. Оригинал: `decks/_dk_src/<имя>.png` (1672×941) — смотри через Read.

**ЭТАЛОН МЕХАНИКИ — `_dk_rep/b_setup.py` и `_dk_rep/v_types.py`** (прочитай): модуль задаёт `W, H, TOP` и `HTML`.
Отличие: импорт `from _i6_replib import bg, img` (а не из _dk_replib).

## Суть
- Подложка — чистый фон `bg("bgk_space")` | `bg("bgk_globe")` (глобус справа внизу) | `bg("bgk_net")` (сеть узлов) первым элементом HTML.
- Поверх фона **вёрсткой** (div/svg) повтори всё содержание оригинала: стеклянные панели, номера-бейджи, плашки, таблицы,
  пакеты-конверты, стрелки, подписи — **тексты дословно, ничего не выдумывать и не выкидывать**.
- Объёмные рисунки (ноутбуки, серверы, маршрутизаторы, облака, иконки, часы, спутники) — вырезкой из оригинала:
  `python _dk_rep/_crop.py <имя> x0 y0 x1 y1 <имя>_что.png` → `img("<имя>_что.png", "left:..px;top:..px;width:..px")`.
  Режь плотно по предмету, без кусков текста/соседних плашек.
- `W, H, TOP = 1672, 941, N` — TOP срезает сверху полосу большого заголовка оригинала (заголовок даёт слайд). Обычно 90–200.
- Стиль 2.6: панели `background:linear-gradient(160deg,rgba(16,40,90,.78),rgba(6,14,36,.9))`, рамка `1.5–2px solid rgba(92,190,255,.75)`,
  `border-radius:14–18px`, свечение `box-shadow:0 0 22px rgba(58,160,255,.35)`. Текст белый/`#b9d2f5`, акцент `#5cd2ff`.
  Шрифты: заголовки плашек `Montserrat` 800, текст `"Golos Text"`, адреса/команды `"JetBrains Mono"`.
  Цвета этапов как в оригинале (жёлтый `#ffc94a`, оранжевый `#ff8a3d`, фиолетовый `#b77bff`, зелёный `#6ee07a`, красный `#ff5a6a`, синий `#3aa0ff`).
- Классы CSS — с уникальным префиксом своей инфографики (например `.n6dh-…`). Анимация: класс `step` на блоках (появляются по порядку DOM,
  3–8 шагов по смыслу). Не вешай свой transform на элемент с классом step — оберни. Движение (пакет летит по линии, пульс) — @keyframes, где уместно.
- В SVG текст красить через `style="fill:…"`; тег `<b>` внутри SVG запрещён.

## Проверка
`python -X utf8 _dk_rep/_cmp6.py i6 <имя> [<имя>...]` (из `decks/`) → `_dk_rep/_cmp/<имя>.jpg` (сверху оригинал, снизу вёрстка). Смотри Read и правь, 2–3 итерации.
Если сверка упала из-за чужого файла — повтори через минуту.

## Правила
- Создаёшь/правишь только `_dk_rep/<свои имена>.py` и `_dk_rep/crops/<свои имена>_*.png`. Больше ничего не трогать, деку в decks/ не собирать
  (сверка пишет во временный файл), git не трогать.
- Отчёт по-русски кратко: что сделано, что непохоже.
