# Задача: инфографика → живая вёрстка на чистом фоне

Деки `decks/bazovye-nastrojki.html` (розовый комикс) и `decks/vlan.html` (пиксельный платформер), сборка `python -X utf8 _dk_build.py`.
Сейчас инфографики пользователя вставлены картинками. Нужно для каждой своей инфографики сделать файл
`decks/_dk_rep/<имя>.py` — тогда сборка покажет вёрстку вместо картинки.

**ЭТАЛОН — `_dk_rep/b_setup.py`. Прочитай целиком и делай так же.** Оригинал: `_dk_src/<имя>.png` (1672×941) — смотри его через Read.

## Суть
- Подложка — **чистый фон** из папки ФОН пользователя: `bg("bgk_...")` первым элементом HTML. Выбери самый похожий на фон оригинала:
  - розовые (base): bgk_laptop (героиня за ноутбуком слева), bgk_sit (сидит с ноутбуком на крыше), bgk_hood (худи слева, светлый город),
    bgk_point (блондинка указывает, крыша), bgk_white (белый с паутиной), bgk_night (ночной город, героиня указывает), bgk_roof (пустая крыша), bgk_fly (героиня в прыжке).
  - пиксельные (vlan): bgk_falls (водопады, персонажи сверху), bgk_hills (холмы, облака), bgk_sky (чистое небо, земля снизу), bgk_ground (небо, персонажи на земле снизу).
  Посмотри фоны: `_dk_src/bgk_*.png`. Если персонаж фона в оригинале стоит в том же месте — отлично; если фон другой — расставь плашки так, чтобы не перекрывать лицо персонажа.
- Поверх фона **вёрсткой** (div/svg) повтори всё содержание оригинала: плашки, ленты-заголовки, таблицы, поля кадров, стрелки, подписи — **тексты дословно**.
- Объёмные рисунки (коммутаторы, ПК, телефоны, конверты, иконки, персонажи, которых нет на фоне) — вырезкой из оригинала:
  `python _dk_rep/_crop.py <имя> x0 y0 x1 y1 <имя>_что.png` → в HTML `img("<имя>_что.png", "left:..px;top:..px;width:..px")`.
- `W, H, TOP = 1672, 941, N` — TOP срезает сверху полосу большого заголовка оригинала (заголовок даёт слайд). Обычно 110–270. **Фон при этом тоже срезается** — это нормально.
- Стиль base: ленты `#ff2e93` Rubik italic 900 uppercase со skew, белые карточки с чёрной обводкой 3px и жёсткой розовой тенью, голубые неоновые провода `#3fe6ff`.
  Стиль vlan: Pixelify Sans для заголовков плашек, Golos Text для текста; плашки с толстой рамкой (белая/коричневая `#3a1606`), без скруглений, жёсткие тени `5px 5px 0 #000`, цвета как в оригинале (оранжево-коричневые ленты `#c8501e`, жёлтый `#ffe14a`, зелёные `#3fae3a`, синие, красные). Поля кадров — цветные ячейки как в оригинале.
- Классы CSS — с уникальным префиксом своей инфографики. Анимация: класс `step` на блоках (появляются по порядку DOM, 3–8 шагов по смыслу). Не вешай свой transform на элемент с классом step — оберни. Движение (конверт летит, порт мигает) — @keyframes, где уместно.

## Проверка
`python -X utf8 _dk_rep/_cmp.py <base|vlan> <имя> [<имя>...]` → `_dk_rep/_cmp/<имя>.jpg` (сверху оригинал, снизу вёрстка). Смотри Read и правь, 2–3 итерации.
Если сверка упала из-за чужого файла — повтори через минуту.

## Правила
- Создаёшь/правишь только `_dk_rep/<свои имена>.py` и `_dk_rep/crops/<свои имена>_*.png`. Больше ничего не трогать, деки не собирать в decks/ (сверка пишет во временный файл), git не трогать.
- Ничего не выдумывать, тексты дословно с оригинала.
- Отчёт по-русски кратко: что сделано, что непохоже.
