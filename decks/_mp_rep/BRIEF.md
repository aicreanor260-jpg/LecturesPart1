# Задача: инфографика MPLS → живая вёрстка на чистом фоне

Дека `decks/mpls.html` (лекция 2.9 MPLS, стиль Гибли). Инфографики автора сейчас вставлены картинками.
Для каждой своей инфографики сделай файл `decks/_mp_rep/<имя>.py` — сборка покажет вёрстку вместо картинки.

**ЭТАЛОН — `_mp_rep/i05a.py`. Прочитай целиком и делай так же.**
Оригинал: `decks/_mp_src/<имя>.png` (1672×941) — смотри через Read. Сверка эталона: `_mp_rep/_cmp/i05a.jpg`.

## Суть
- Подложка — **чистый фон** комплекта: `bg("bgk_NN")` первым элементом HTML. Список фонов с описанием персонажей — `_mp_rep/BGLIST.md`,
  сами картинки — `_mp_src/bgk_NN.png` (смотри Read). Выбери фон, где персонажи стоят там же, где в оригинале
  (часто совпадает один в один). Если такого нет — ближайший, и расставь плашки так, чтобы не закрыть лица.
- Поверх фона **вёрсткой** (div / inline svg) повтори всё содержание оригинала: плашки, заголовки блоков, таблицы, стрелки,
  поля пакетов и меток, подписи — **тексты дословно, ничего не добавлять и не выкидывать**.
- Объёмные рисунки (маршрутизаторы, ПК, серверы, иконки, конверты; персонажи, которых нет на фоне) — вырезкой из оригинала:
  `python -X utf8 _mp_rep/_crop.py <имя> x0 y0 x1 y1 <имя>_что.png [key]` (key — убрать однотонный фон вокруг) →
  в HTML `img("<имя>_что.png", "left:..px;top:..px;width:..px")`.
- `W, H, TOP = 1672, 941, N` — TOP срезает сверху полосу большого заголовка оригинала (заголовок даёт слайд деки). Обычно 120–200.
- Стиль как в оригинале: кремовые панели `#fdf8ea` с синей рамкой `#1f63c6` и скруглением, тёмно-синие заголовки Rubik 900,
  текст Golos Text, метки — оранжево-красные поля `#f2694a`, светло-голубые/бирюзовые подложки, цветные пилюли как на картинке.
- Классы CSS — с уникальным префиксом своей инфографики (`.i37-…`). Анимация: класс `step` на блоках (появляются по порядку DOM,
  3–6 шагов по смыслу). Не вешай свой transform на элемент с классом step — оберни. Лёгкое движение (метка/пакет) — @keyframes.
- Текст внутри inline-SVG — цвет через `style="fill:…"`; `<b>` внутри SVG запрещён.

## Проверка
`python -X utf8 _mp_rep/_cmp.py <имя> [<имя>...]` → `_mp_rep/_cmp/<имя>.jpg` (сверху оригинал, снизу вёрстка). Смотри Read и правь,
2–3 итерации, пока не будет похоже по раскладке и тексту. Сверка собирает деку во временный файл ~30 с.
Если в выводе «ОШИБКА вёрстки» чужого файла — это не твоё, игнорируй.

## Правила
- Создаёшь/правишь только `_mp_rep/<свои имена>.py` и `_mp_rep/crops/<свои имена>_*.png`. Больше ничего не трогать,
  `mpls.html` не собирать, git не трогать.
- Ничего не выдумывать, тексты дословно с оригинала (опечатки оригинала — как есть).
- Отчёт по-русски кратко: какие сделаны, что осталось непохожим.
